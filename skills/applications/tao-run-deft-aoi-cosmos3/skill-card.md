## Description: <br>
Run the state-backed DEFT AOI loop for Cosmos3 Nano with Cosmos Framework, canonical NVPAW JSONL, task-aware real-image mining, Framework DCP checkpoints, and the recorded exact five-component F1 Benchmark gate. <br>

## Use Case: <br>
Improve multi-task PCB inspection from isolated Proxy, Benchmark, and Mining JSONL. Proxy errors drive RCCA and real-data selection; only the frozen Benchmark stops the loop. Training sets grow monotonically from Mining records and remain isolated from evaluation targets. <br>

## Known Risks and Mitigations: <br>
Data leakage, changed Benchmark input, incomplete DCP, evaluator drift, or prediction-coverage gaps invalidate the result. SHA-256 seals, split validation, DCP completeness checks, exact-key handoff, atomic state commits, and fail-closed KPI coverage mitigate these risks. <br>
